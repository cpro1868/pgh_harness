# PG Harness 项目启动文档

> 面向日常使用者的自助启动/停止/排障指南。读完本文即可完全不依赖 AI 助手独立操作。

## 一、环境要求（一次性检查）

| 依赖 | 要求 | 检查命令 |
| --- | --- | --- |
| Node.js | **v22 或更高**（必需，用了原生 SQLite 与类型剥离） | `node -v` |
| pnpm | 8+（开发/质量门禁时才需要） | `pnpm -v` |
| 浏览器 | Chrome / Edge 任意现代版本 | — |

> 首次使用无需 `pnpm install`——服务端零第三方依赖（纯 Node 标准库），脚本直接跑 TypeScript 源码。

## 二、启动（三条路任选）

### 方式 1：后台守护启动（推荐，日常使用）

```powershell
cd G:\Projects\Agent\harness
pwsh scripts\start-bg.ps1
```

- 自动检测 Node 版本、写入单实例锁、拉起服务、打开浏览器
- 访问地址：**http://127.0.0.1:3210/run-chat.html**
- 日志：`~\.pg_harness\logs\pgh-server-out.log`（正常输出）/ `pgh-server-err.log`（错误）
- 不想自动开浏览器：`pwsh scripts\start-bg.ps1 -NoBrowser`
- 换端口：`pwsh scripts\start-bg.ps1 -Port 3211`

### 方式 2：前台开发模式（看实时日志，Ctrl+C 停止）

```powershell
cd G:\Projects\Agent\harness
pwsh scripts\start-dev.ps1
```

### 方式 3：最朴素直启（应急，任何终端可用）

```powershell
node --experimental-strip-types apps\server\src\index.ts --port 3210
```

## 三、停止

```powershell
pwsh scripts\stop-dev.ps1
```

- 内置确定性硬杀：按单实例锁 PID + 端口双保险 `taskkill /T /F`，同时清理锁文件
- 停止后重跑启动脚本即可，无需清理任何东西

## 四、健康检查与排障

### 快速确认服务是否活着

```powershell
# 浏览器访问
http://127.0.0.1:3210/api/health
# 期望返回：{"code":0,"status":"ok","version":"0.2.0","port":3210,"pid":<进程号>}
```

### 常见问题速查

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 启动脚本报 "already running" | 已有实例在跑（正常） | 直接用浏览器访问即可；要重启先 `stop-dev.ps1` |
| 健康检查 404/拒绝连接 | 服务没起来 | 看 `~\.pg_harness\logs\pgh-server-err.log` 最后几行 |
| 刷新页面后看到旧界面 | 浏览器缓存 | `Ctrl+Shift+R` 强制刷新 |
| 调模型报 520/terminated | 上游 Cloudflare 网关瞬态故障 | 系统已自动重试 3 次；仍失败等几分钟再试 |
| 发消息后长时间「等待授权」 | edit 档下工具操作需人工审批 | 点对话中的琥珀色审批卡放行/拒绝，或顶栏切换授权档位 |
| 409 工作区被占用 | 上一会话回合未结束持锁 | 对该会话点 ⏹ 停止，或 `stop-dev.ps1` 重启清锁 |

## 五、数据与安全

| 位置 | 内容 | 注意 |
| --- | --- | --- |
| `~\.pg_harness\pgh.db` | 全部会话/事件/配置（SQLite，自动 WAL） | **勿手动删**，删了会话历史全丢 |
| `~\.pg_harness\master.key` | 凭据加密主密钥 | **勿删勿外传**，丢了已存 API Key 无法解密 |
| `~\.pg_harness\logs\` | 运行日志 | 可随时清理 |

- 服务只监听 `127.0.0.1` 回环地址，本机以外无法访问
- API Key 加密存储，明文永不出机、不入日志

## 六、质量门禁（改代码后跑）

```powershell
pnpm install          # 仅首次/依赖变更后
pnpm check            # lint + typecheck + test 三段全绿才算过
node scripts\self-check.ts   # 离线集成自检（6 项）
```

## 七、一图流

```
启动:  pwsh scripts\start-bg.ps1   →  http://127.0.0.1:3210/run-chat.html
停止:  pwsh scripts\stop-dev.ps1
体检:  http://127.0.0.1:3210/api/health
日志:  ~\.pg_harness\logs\
数据:  ~\.pg_harness\pgh.db + master.key（勿动）
改码:  pnpm check → self-check → 重启生效
```

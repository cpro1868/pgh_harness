## 1. 概述与全新系统导航结构

本原型严格遵循**「运行态 (Run-time) 与 配置态 (Config-time) 彻底解耦」**的设计铁律，在最左侧建立一级系统活动导航栏 (Activity Bar)，并以**工作区 (Workspace)** 作为全局绝对物理锚点。

模块化静态原型工程组织如下：

```
docs/阶段-1-需求/prototype/
├─ index.html                 # 原型总览大屏与系统控制中枢导航
├─ css/
│   └─ shared.css             # 生产级暗色工程师主题 (统一 Activity Bar、紧凑顶栏、暗色高密度)
├─ js/
│   └─ mock-data.js           # 完整业务实体模拟数据库 (多工作区、多Provider、知识库、流水线任务、BPMN实例、MCP、Skills)
│
├─ 【运行态 (Run-time Workspace)】
│   ├─ run-chat.html          # 主对话工作台 (模式B：底部开启子任务委派Subagents开关、工作区锁定、切模型)
│   ├─ run-pipeline.html      # ★模式A：多角色流水线任务运行列表大屏 (并发统计、任务进度表格、一键发起新流水线)
│   ├─ run-pipeline-detail.html# ★模式A：独立任务工作台 (绑定工作区、人机指令对话窗口、阶段泳道、工件库与Gatekeeper)
│   ├─ run-workflow.html      # ★模式C：BPMN 业务工作流实例列表大屏 (实例并发统计、节点过滤、一键发起新工作流实例)
│   ├─ run-workflow-detail.html# ★模式C：独立实例追踪工作台 (绑定工作区、SVG动态高亮、网关计算、干预对话流、变量总线)
│   ├─ run-terminal.html      # 执行与长任务 (持久长驻 Shell 树、实时管道输出、Job 管理与 SIGKILL 中断)
│   └─ run-trajectory.html    # 事件轨迹审计 (底层连续 events 表、模型当时完整请求快照重构、一键 Fork 会话)
│
└─ 【配置态 (Settings & Governance)】
    ├─ config-workspace.html  # 工作区初始化设定 (定义项目规范、AGENTS.md生成模板、Git提交约束、全局忽略黑名单)
    ├─ config-knowledge.html  # 独立知识库管理中心 (独立向量化嵌入模型设定、多库集合、分块策略、现场检索沙盒)
    ├─ config-providers.html  # 多模型中心 (多端点管理、完整新增/编辑Provider弹窗、/models自动同步、独立压缩模型)
    ├─ config-pipelines.html  # ★模式A：多角色流水线模板库 (多模板清单与快捷发起)
    ├─ config-pipeline-detail.html # ★模式A：流水线角色与流转设置工作台 (阶段顺序编排、角色定义、Prompt模板、工具白名单、工件传递与Gatekeeper)
    ├─ config-workflows.html  # ★模式C：BPMN 业务流程定义与设计 (导入/导出 BPMN 2.0 XML、节点Agent绑定、表达式配置)
    ├─ config-permissions.html# 权限与沙箱 (三档预设、命令前缀/路径通配符/域名规则表、Deny>Ask>Allow)
    ├─ config-mcp.html        # MCP 扩展中心 (添加 stdio/HTTP Server 差异化表单、连通性探测、工具暴露清单与单项权限)
    ├─ config-skills.html     # Skills 技能库 (项目/全局技能扫描、在线 Markdown 编辑器预览与修改、触发意图映射)
    └─ config-plugins.html    # 插件内核装配 (harness.yml 映射、10大核心插件拓扑关系、提供/注入服务检查)
```

## 2. 核心架构与业务闭环交互规范

### 2.1 物理锚点：工作区锁定与新会话选择规范
- **新会话选择 (Select on Create)**：
  - 用户新建会话时，在主聊天界面底部输入框上方醒目提供**【更换工作区 (文件夹)...】**按钮；
  - 点击可呼出系统文件夹选择，或直接从候选库（最近打开的 Git 仓库）中快速点选；
- **运行期绝对锁定 (Locked at Runtime)**：
  - 一旦用户发出第一条消息或开始执行任务，顶栏工作区自动进入**物理锁定状态 🔒 (`.locked-workspace-chip`)**；
  - 严禁在当前会话中途随意更换工作路径，所有文件与 Shell 工具严格限制在此工作区内执行；换项目只需新建独立会话。

### 2.2 多 Provider 资产管理与会话即时切模型
- **配置态 (`config-providers.html`)**：
  - 支持同时配置维护多个 Provider（如 DeepSeek 官方、OpenRouter 聚合端点、本地 Ollama 实例）；
  - 全局汇聚全量可用模型资产清单，标注上下文窗口、工具支持与推理能力，支持指定独立的压缩轻量模型；
- **运行态即时切换 (`run-chat.html`)**：
  - 工作台顶栏常驻「当前模型」选择器，用户在对话过程中可根据任务难度随时下拉切换调用的模型（如简单编码用 DeepSeek V3，复杂算法秒切 DeepSeek R1 推理模型）。

### 2.3 关键扩展能力管理闭环 (全要素落地)
- **MCP 扩展中心 (`config-mcp.html`)**：
  - 支持快捷添加并挂载外部 MCP Server，**弹窗内严格根据连接类别动态切换字段**：
    - **`stdio` 模式**：输入主执行命令 (Command)、多行启动参数 (Args)、环境变量注入字典 (Env Key-Value)；
    - **`HTTP/SSE` 模式**：输入远程 URL 端点、自定义 HTTP Headers (鉴权 Token)、连接超时设定；
  - 提供单项「Ping 探测」测试网络与子进程握手状态；
  - 完整呈现发现的工具清单，并支持直接设置单个工具的免审批策略（Allow / Ask）。
- **Skills 技能库与在线编辑 (`config-skills.html`)**：
  - 严格遵循渐进披露架构，清晰展示技能目录与触发意图 (`when-to-use`)；
  - **支持在线 Markdown 编辑**，用户可现场审阅或微调 `SKILL.md` 指令正文；
  - 支持模型按需调用总开关。
- **插件内核拓扑监控 (`config-plugins.html`)**：
  - 1:1 映射根目录 `harness.yml`，清晰展示 10 大核心插件的加载顺序、服务提供 (`ctx.provide`)、依赖注入 (`ctx.inject`) 与 Fail-Fast 保护状态。

### 2.4 主工作台紧凑比例与多模型即时切换 (`run-chat.html`)
- **顶栏瘦身至 38px**：符合现代专业 IDE 紧凑高密度规范，消除元素过大遮挡主界面的问题；
- **运行期随时切模型**：顶栏微型选择器直接列出各 Provider 已启用的模型，对话中途随时秒切；
- **新会话轻量工作区点选**：输入框上方提供单行轻量【选择工作区文件夹...】按钮，会话开始后立即只读物理锁定 🔒；
- **模式B：子任务委派开关 (Subagents)**：输入框下方常驻「⚡ 开启子任务委派 (Subagents)」复选框，选中后为当前会话注入 `spawn_agent` 工具能力。

### 2.5 多智能体协作与工作流体系 (模式A与模式C · 独立列表与工作台双层闭环)
- **模式A：多角色流水线 (`run-pipeline.html` + `run-pipeline-create.html` + `run-pipeline-detail.html` + `config-pipelines.html` + `config-pipeline-detail.html`)**：
  - **任务列表大屏 (`run-pipeline.html`)**：提供全量流水线任务表格、状态过滤，每行均提供**【编辑配置】**与【进入工作台】操作；
  - **步骤定制工作台 (`run-pipeline-create.html`)**：支持自由增删步骤、调换顺序、指定每个步骤由哪个 Agent 角色负责、设定具体 Prompt 任务、**将「产出交付工件」改良为「产出交付工件至（选填目录，留空自动通过 Git 状态追踪改动代码）」**，避免强填死文件的繁琐；
  - **独立任务工作台 (`run-pipeline-detail.html`)**：顶栏显式锁定工作区绝对路径 🔒、顶置四阶段泳道、具备**人机协同指令对话窗口（人类随时向当前 Agent 下达补充指令）**与工件审批门；
  - **模板库与角色规则设定 (`config-pipelines.html` + `config-pipeline-detail.html`)**：管理流水线可复用模板。
- **模式C：BPMN 2.0 业务流程引擎 (`run-workflow.html` + `run-workflow-detail.html` + `config-workflows.html` + `config-workflow-design.html`)**：
  - **BPMN 流程定义资产库 (`config-workflows.html`)**：
    - 展示所有已定义的 BPMN 业务流程模型大表（版本、节点数、网关数、XML 文件源、活跃实例数）；
    - **表格每行提供【查看 XML】与【Dify 可视化设计 &rarr;】专属操作**；
  - **Dify 风格 BPMN 可视化拖拽编排工作台 (`config-workflow-design.html`)**：
    - 参考 Dify 现代节点卡片理念，左侧提供**节点物料面板 (Node Palette)**（事件节点、Agent ServiceTask、人工 UserTask、排他网关等）；
    - 中央提供**无限网格点阵画布 (Infinite Canvas)**，支持节点卡片展示、锚点、贝塞尔曲线连线与分支走向；
    - 右侧提供**节点检查器抽屉 (Node Inspector Drawer)**，点击任意节点可配置该节点绑定的 Agent 角色、专属 Prompt、模型选择、变量总线输出映射 (Variables Mapping) 与排他网关表达式评估；
    - 顶栏支持标准 **BPMN 2.0 XML** 的导入与导出；
  - **实例列表大屏 (`run-workflow.html`)**：展示所有并发流程实例，支持按模型筛选与「启动新工作流实例」向导弹窗；
  - **独立实例追踪工作台 (`run-workflow-detail.html`)**：专享高保真动态 SVG 拓扑大图（绿色流经、黄色评估）、**人工干预对话流**与上下文变量总线。

### 2.6 工作区记忆策略与受控存储中心 (`config-memories.html`)
- **全自动 vs 半自动反思机制对比切换**：
  - 卡片交互直观呈现两种沉淀模式的差异：全自动静默无感入库 vs 半自动人工审核确认；
  - 辅以「什么场景选哪个」的人话说明，帮助开发者根据个人喜好与团队协作场景进行取舍。
- **四大工作区存储策略卡片 (只读详情态)**：
  - 包含：未启用记忆 (Disabled)、纯 Markdown 文件 (`.harness/memory.md`)、本地嵌入式 SQLite (`node:sqlite` 零原生编译，支持相对/绝对路径与 FTS5 索引)、Markdown 文件 + 向量双轨模式 (Markdown 真相源 + 本地 BGE-M3 向量加速)；
- **双重受控操作闭环 (参数修改 + 模式变更向导)**：
  - **修改参数按钮**：不换介质直接呼出抽屉修改当前路径、表名、Embedding 模型与阈值等运行时参数；
  - **变更存储模式与迁移向导**：切换模式时，在向导内部**动态联动展开目标模式的专属参数配置表单**，并提供「全新起步丢弃测试数据」与「平滑数据无损迁移」精准分流。

### 2.7 BPMN 编排工作台沉浸体验 (`config-workflow-design.html`)
- **双侧面板无缝折叠**：
  - 左侧物料面板 (Node Palette) 支持一键折叠为 36px 极窄竖排唤醒条；
  - 右侧参数检查器 (Node Inspector Drawer) 支持右上角按钮或直接收起；
  - 点击任意节点自动顺畅唤醒右侧面板，全景状态下中央点阵画布拥有 100% 满屏无遮挡视野。

### 2.8 系统全局设置中心与导航瘦身 (`config-settings.html`)
- **Activity Bar 优雅减负**：左侧由原来 10 个臃肿图标精简收敛为高频业务核心（工作区、记忆、模型、知识库、流水线、BPMN、Skills），底部常驻齿轮进入【系统设置】；
- **设置中心多维聚合 Tab**：
  - ⚙️ **基础运行与网络**：服务端口 (Port 3000)、0.0.0.0 暴露与 HARNESS_ACCESS_TOKEN 鉴权、数据持久化目录 (`~/.harness`)；
  - 🎨 **外观主题与字体**：深色极客 / Slate 蓝调 / OLED 纯黑三套主题，代码字体与紧凑度；
  - 🛡️ **安全权限与沙箱预设**：只读/编辑/全权模式；
  - 🧩 **MCP 外部连接**：MCP 服务池运行状态；
  - 🔌 **内核插件编排**：10 大核心内置插件依赖拓扑。

```bash
# 启动本地原型查看（以默认浏览器打开原型导航中心）
start G:\Projects\Agent\harness\docs\阶段-1-需求\prototype\index.html
```

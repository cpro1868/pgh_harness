PRD：在线支付校验模块

版本：v0.1（Agent 自动生成） · 状态：待确认 · 来源：需求探索会话 req_...

1. 背景与目标

为中小团队（5-20 人）提供轻量级支付校验能力，支持 card / paypal / bank_transfer 三种支付方式的合法性校验与差异化手续费计算，以 Node.js 模块形式交付，零外部依赖。

2. 目标用户

  • 中小团队后端开发者（5-20 人规模），需要快速集成支付校验能力
  • SaaS 平台开发者，需要灵活的支付方式扩展

3. 功能需求

功能描述优先级
支付方式校验支持 card / paypal / bank_transfer 三种方式的合法性校验（白名单机制）P0
手续费计算按支付方式差异化计算手续费（card 2.9%，其余 0%）P0
金额边界处理NaN / Infinity / 负数 / 超上限拒绝P0
错误码体系统一错误码返回（invalid_method / unsupported_method / invalid_amount）P1

4. 非功能需求

  • 零外部依赖（纯 Node.js 标准库）
  • 单元测试覆盖率 ≥ 90%
  • 单次校验响应 < 1ms（纯计算，无 IO）

5. 验收标准

  • 所有 P0 功能有对应单元测试且全部通过
  • 边界用例覆盖：空值 / NaN / 负数 / 超大金额 / 非法字符串 / 原型链属性名
  • Agent 产出文档（REVIEW.md / FIX-REPORT.md）完整

6. 选定方案

方案 A · 策略模式：每种支付方式独立策略类，手续费按基点（bp）计算，内部金额以分（cents）为单位避免浮点精度问题。FEE_RULES 使用 Object.freeze 冻结防运行时篡改。

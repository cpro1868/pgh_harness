多角色流水线定义与模板设定

💡 什么是角色流水线 (Role Pipeline)？

通过定义标准的「需求分析 → 架构设计 → 编码实现 → 测试验证」等有序角色阶段，将上一 Agent 产出的 Artifact 作为输入严格注入下一阶段，实现高质量工程流水线。

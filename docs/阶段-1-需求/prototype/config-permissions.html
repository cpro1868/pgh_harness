安全预设与细粒度权限控制表

控制 Agent 在本地环境的每一次动作。未命中的操作遵循 Fail-Closed 原则自动阻断。

全局安全预设 (Preset)

只读模式 (Plan Mode) 安全只读

仅允许只读搜索与文件查看，所有修改文件与命令执行严格 Deny 拒绝。

编辑模式 (Edit - 默认) 生效中

只读操作放行，写文件必须人工 Diff 审批，Shell 执行根据白名单严格拦截。

全权模式 (Autonomous) 慎用

已知安全工具与命令全部免问放行，仅越界与不可逆操作拦截。

参数模式匹配规则表 (Rules Table)

支持命令前缀白名单、相对路径通配符与域名过滤。

工具 (Tool) 参数模式 (Pattern) 执行动作 (Action) 规则描述 操作
bash git status|git diff|git log ALLOW Git 只读查询免审批直接执行 编辑
bash npm test|node --test ALLOW 单元测试运行放行 编辑
bash rm -rf|del /s DENY 高危破坏性删除命令严格拒绝 编辑

write_file src/** ASK 源代码修改必须弹窗人工审批 编辑
